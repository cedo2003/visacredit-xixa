## 🚀 Démarrage Rapide

1. Accédez au site Visacredit XIXA
2. Cliquez sur **Connexion**
3. Entrez l'un des numéros de téléphone ci-dessus
4. Entrez le mot de passe associé
5. Cliquez sur **Se connecter**
